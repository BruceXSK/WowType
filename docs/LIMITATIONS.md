# 目前做不到的

这一页是给用户看的：哪些事现在做不了、为什么。

- 安装包只有 x86_64 和 arm64（Arch 只有 x86_64）；deb / rpm / Arch / Nix 以外的发行版要从源码构建
- 没有用语料训练的语言模型，「祝你 / 祝您」「在 / 再」这类同音词，没用过时只能靠词频排
- 语音输入只有一个识别结果，不能在候选里改；不能选麦克风（用系统默认的输入设备）
- [跨设备复制粘贴](SYNC.md)只有 Linux 接上了，macOS、Windows 还没有；只传文字，不传图片和文件；GNOME 的 Wayland 会话里可能发不出去（fcitx5 读不到别的应用里复制的内容），没验证过；分不出密码管理器复制的密码，会一起传过去
